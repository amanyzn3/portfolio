# Aman Yazeen — 3D WebGL Portfolio

An award-winning, scroll-driven 3D WebGL portfolio built with Three.js, React Three Fiber, GSAP ScrollTrigger, and Tailwind CSS. Showcases Aman Yazeen's full-stack software platforms, AI copilots, business intelligence models, and career milestones along an illuminated celestial staircase.

---

## 🚀 Featured Projects & Milestones
- **SyncHub**: Flagship enterprise workspace unifying Kanban workflows, contextual team chat with one-tap "Turn into Task" conversion, and an embedded Google Gemini AI copilot.
- **SyncHub Telemetry & Analytics**: Executive Power BI dashboard modeling 30 cross-functional deliverables, 16 completed deliverables, and a 52% efficiency index.
- **NinoCare**: Final-year pediatric companion app led and presented by Aman Yazeen, featuring infant percentile growth tracking, automated vaccination calendar alerts, and AI triage guidance.
- **Personal Habits Arena**: Gamified personal habit arena with streak counters, XP level progression, daily challenge quests, and an AI habit motivator.
- **IIT Madras Faculty Evaluation**: Elite certification (67%) in algorithmic problem solving, recursion, and data structures in Python from NPTEL & IIT Madras.
- **JHF IT Innovations**: Active Software Engineering Internship.

---

## 🛠️ Tech Stack
- **3D & Rendering**: Three.js, `@react-three/fiber`, `@react-three/drei`, CatmullRom spline camera interpolation
- **Frontend Framework**: React 19, Vite
- **Animation & Motion**: GSAP `ScrollTrigger`
- **Styling**: Tailwind CSS, Vanilla CSS, Glassmorphism, Custom Design System
- **Icons**: Lucide React

---

## 💻 Getting Started Locally

```bash
# Clone the repository
git clone https://github.com/amanyzn3/portfolio.git

# Navigate into project directory
cd portfolio

# Install dependencies
npm install

# Start local development server
npm run dev
```

---

## 📦 Build for Production

```bash
npm run build
```
